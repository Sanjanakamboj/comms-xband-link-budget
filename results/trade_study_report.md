# Milestone 2 Trade-Study Report

Baseline worst-case range: 402,000 km
Baseline worst-case margin: +1.48 dB (2.00 Mbps operating rate)
Maximum supported data rate at worst-case range (0 dB margin): 2.81 Mbps
Effect of doubling range (worst-case): margin drops by 6.02 dB
Effect of doubling data rate: margin drops by 3.01 dB
Required Tx power for 0 dB margin: 2.84 W (+4.54 dBW)
Required Tx power for +3 dB margin: 5.67 W (+7.54 dBW)
Required ground dish diameter for 0 dB margin: 9.11 m
Required ground dish diameter for +3 dB margin: 12.87 m
